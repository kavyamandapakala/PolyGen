# PolyGen – Generative Text-to-3D Asset Pipeline

## 1. Project Overview
PolyGen is a Generative AI project focused on creating 3D assets from textual descriptions.

## 2. Project Objective
The objective is to explore real-world Generative AI workflows and understand how text prompts can be used to generate 3D assets.

## 3. Key Project Areas
- Understanding text-to-3D generation.
- Exploring Large Language Models and Generative AI.
- Studying prompt engineering techniques.
- Identifying suitable AI APIs and frameworks.
- Understanding 3D asset generation workflows.
- Evaluating generated outputs.
